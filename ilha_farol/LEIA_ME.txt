O MISTÉRIO DA ILHA DO FAROL — ASSETS 06 A 37
Pacote corrigido: Bia é a protagonista; Faísca acompanha Bia; Júlia ajuda com a câmera.

CONTEÚDO
32 pastas, uma para cada asset, com exatamente um PNG e um JSON correspondente.
O JSON geral na raiz reúne o planejamento, as 69 sequências e as regras de integração.
Os assets 10 e 11 já são as versões corrigidas de Bia; a folha 10 é a versão com maior espaçamento.
O asset 27 contém ações da mesma Bia jogável. Não criar uma segunda Bia como NPC.
Os PNGs foram copiados sem alterar seus pixels, dimensões ou transparência original.

COMO USAR NO ANTIGRAVITY
1. Extraia o ZIP. A pasta principal se chama ilha_farol.
2. Coloque essa pasta no diretório de arquivos públicos do projeto, acessível em assets/ilha_farol/.
   A localização física desse diretório depende do projeto. Se a URL for diferente, ajuste assetBasePath no JSON geral.
3. Peça ao Antigravity para integrar pelo JSON geral. Os caminhos para os 32 PNGs já incluem suas subpastas.
4. Para trabalhar em um único asset, use o PNG e o JSON dentro da pasta dele.
   No JSON individual, frames e meta são o atlas; phaserAnimations contém as animações dessa imagem.
   behaviorConfig descreve suas regras e dependencies aponta para assets relacionados.
5. Implemente os eventos e controladores indicados no JSON geral. Configuração JSON não executa sozinha a física e a lógica do jogo.
6. Teste inicialmente Bia, Faísca, conchas e latido; depois integre inimigos, NPCs e plataformas.
